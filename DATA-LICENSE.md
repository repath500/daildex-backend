# Data and third-party licences

The MIT licence covers the DáilDex code and documentation in this repository.
It does not cover the parliamentary records fetched by the ingestion jobs,
third-party dependencies, external model weights or external publisher material.

The Houses of the Oireachtas publishes the source parliamentary records. Retain
source links and the Oireachtas Open Data PSI Licence attribution. The exact
attribution and licence link used in API responses are defined in
`packages/core/src/public-api/service.ts` and in the public MCP instructions.
Consult those linked source terms before redistributing records.

This repository includes no production data export or subscriber records.
